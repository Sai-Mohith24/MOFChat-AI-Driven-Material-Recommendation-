MOFChat · Team 09 · 6

Instead of generating pandas code like ChatMOF, the LLM fills a small JSON schema. Each field can be validated, SQL is compiled from whitelisted column names with bound parameters on a read-only connection, so a wrong column or an injection is impossible. The hybrid planner adds to the LLM plan the facts a deterministic rule parser is certain about: explicit numbers, metals, limits and application keywords. If the question names an application such as CO2 capture, objectives the question does not mention are dropped so the preset decides the ranking.
