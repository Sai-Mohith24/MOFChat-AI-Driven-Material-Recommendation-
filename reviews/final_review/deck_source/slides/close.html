Run the app with streamlit run app.py from the Final-project folder. Open the sidebar's All language models list first to show which models are ready. For each question, open How this answer was produced to show the plan, the SQL and the validator result, and point at the Answered with line. If the network is down, switch the model to local Llama 3 or turn the language model off: the rule-based planner still answers every demo question.
