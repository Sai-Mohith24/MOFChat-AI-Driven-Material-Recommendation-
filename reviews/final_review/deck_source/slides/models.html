MOFChat · Team 09 · 7

ChatMOF depends on GPT-4. MOFChat treats the LLM as an interchangeable part behind a registry: each model reports whether it is usable right now, every call is throttled to that model's free-tier budget, and a rate limit or outage moves the request to the next model. If no model answers, the rule parser and a template still answer the question. The app's sidebar picks the model and every answer says which model wrote it. For the evaluation, fallback is switched off so each score belongs to one model.
