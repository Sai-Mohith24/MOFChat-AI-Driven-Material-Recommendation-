This is a real first draft from testing the app. Every number in it exists somewhere in the results, so a check that only asks "is this number in the data" passes it. The claim check finds the property from the unit or the nearest property name, finds the MOFs from the IDs in the sentence or words like "these" and "all five", and checks each one against the database. Pareto-front claims are checked against the NSGA-II ranks. A failed draft is regenerated once with the exact problems listed; anything still wrong is flagged, and the verified table is always shown. What it does not check: free-text reasoning without numbers, such as a wrong formula.
