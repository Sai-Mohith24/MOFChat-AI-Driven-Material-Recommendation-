MOFChat · Team 09 · 9

Each model planned both question sets alone, with fallback switched off, so every score belongs to one model. Nemotron ran on the held-out set only because OpenRouter's free tier allows about 50 requests a day. Flash-Lite's 13 errors and its slower development run came from Google's free tier being overloaded at the time; on the held-out run it took 1.5 seconds per call. Qwen 3.8 is a reasoning model and uses Groq's 8,000 tokens per minute quickly, hence 20 seconds. Gemini 3.5 Flash ran out of its daily free quota mid-run, so we report it as missing rather than publish a score that would really measure the rule-parser fallback. The default order is Flash-Lite, GPT-OSS 120B, Qwen, then local Llama 3.
