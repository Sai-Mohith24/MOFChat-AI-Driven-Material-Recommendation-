Problem and base paper

Choosing a MOF means searching 12,020 structures on several properties at once

ChatMOF (Kang & Kim, Nat. Commun. 2024) showed that a GPT-4 agent can search, predict and generate MOFs from natural language.

Its own analysis lists the weaknesses we set out to fix.

LLM-written code with logic errors

Token-limit failures on large tables (4 % of searches)

A proprietary, online LLM

A dedicated pretrained model per property

No validation of the generated answer

MOFChat · Team 09 · 2

MOFs are crystalline porous materials built from metal nodes and organic linkers, candidates for carbon capture, gas storage, separations and catalysis. Picking one means filtering thousands of structures on pore size, surface area, density and so on, plus domain knowledge. ChatMOF is our base paper. Its own error analysis names these five weaknesses; each later slide shows how MOFChat addresses one of them.
